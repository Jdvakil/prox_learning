# Experiments

A robot arm has cameras and 40 small distance sensors (the skin). The job is to pick an object in a tight space. These tests ask if the skin cuts crashes when the cameras cannot see an obstacle.

**ACT** is the robot with cameras only. **PACT** is the same robot plus the skin.

For run commands and full tables, read `[README.md](README.md)` section 14. For the story of the numbers, read `[STATUS.md](STATUS.md)`.

Each cell is one sentence. Results use `x% vs y%` plus a short note.


| Experiment                           | Description                                                                                                                                   | Results                                                                                                                                                                                          |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ACT vs PACT (headline)               | Train two robots on 105 examples. ACT sees cameras only. PACT also gets raw skin distances. Test 50 times with a bar that cameras cannot see. | Crashes **66% (ACT) vs 40% (PACT)** when the bar is hidden (p = 0.016); no-bar crashes 60% vs 58%; visible-bar crashes 64% vs 50%; pick success 36% vs 30% is noise. Safer, not a better picker. |
| Do the skin sensors work?            | Check if the 40 distance sensors on the arm see around the arm, measure distance well, and still work in blur and dark.                       | 83% vs 10% of directions seen (skin vs wrist camera); 5.6 mm error on a pipe; skin numbers stay the same in blur and darkness.                                                                   |
| Does skin help on an open table?     | Check if extra distance data helps when cameras already see the object the whole time.                                                        | ~0% extra value from skin; later tests move the robot into a tight box where cameras miss things.                                                                                                |
| Does the flinch network work?        | Train a small network that reads the skin and outputs a "move away" joint motion, then grade it fairly.                                       | Direction score 0.924 vs 0.926 (fair split vs easy split); when the obstacle is closest the push is only 64% as large as it should be.                                                           |
| Which flinch network is best?        | Train the same flinch network three times on different practice sets and keep the best one.                                                   | Error 0.009 vs 0.011 vs 0.015 (best vs older two); the third train is the best.                                                                                                                  |
| How far ahead should cameras plan?   | Train a cameras-only robot with short vs long motion plans, and with less vs more practice.                                                   | Crashes 30% vs 60% (short plan vs long plan); crashes 60% vs 20% (less practice vs more practice); long plans crash more.                                                                        |
| First try: add skin to the brain     | Give the robot both cameras and skin, train it on the first obstacle set, and compare it to cameras only.                                     | 0% gain vs cameras only in 50 attempts (p = 0.76); adding skin did not help.                                                                                                                     |
| Does the brain use the skin?         | After that first try, turn the skin readings to zero and see if the robot's planned move changes.                                             | Planned move changes by ~0.005; the brain was not using the skin.                                                                                                                                |
| Can skin show a dodge? (set 1)       | Ask if you can tell a swerve from a straight reach by looking only at the skin numbers.                                                       | Guess scores 0.50 vs 0.53 vs 0.34–0.56 (skin vs processed skin vs joint angles); all are a coin flip.                                                                                            |
| Can skin show a dodge? (set 2)       | Repeat that question on new data where a bar is in the way but cameras cannot see it.                                                         | Swerve guess ~0.75 vs 0.50 coin-flip; "is the bar there?" guess 0.40–0.52 vs 0.72–0.78 on set 1; you can see a swerve, not the bar itself.                                                       |
| Does skin help guess the next move?  | Measure how well each input predicts the expert's next motion: cameras, raw skin, or the processed flinch signal.                             | Error 0.0595 vs 0.0755 vs 0.0830 (raw skin vs cameras vs flinch signal); raw skin is ~21% better.                                                                                                |
| Processed flinch instead of raw skin | Same test, but feed the brain the flinch network's inner signal instead of the 40 raw distances.                                              | Hidden-bar crashes 66% vs 72% (cameras vs flinch signal); no-bar 60% vs 64%; visible-bar 64% vs 58%; the processed signal made crashes worse.                                                    |
| Train with blurry cameras            | Train cameras-only robots on blurry pictures, then test them on clear pictures.                                                               | Hidden pick success 36% vs 0% vs 40% vs 24% (no blur vs mild vs medium vs heavy); luck is ±40 points in 25 attempts; blur did not make a clean pattern.                                          |
| What is in the training videos?      | Count how often the expert swerves, touches things, and how often the skin sees something close.                                              | 43% of bar runs actually swerve (49/113); 40% of runs scrape on the way in; close skin 86% vs 74% (bar vs no bar); mean swerve 3.8 cm vs 0.5 cm.                                                 |
| Second try with cleaned data         | Train again after dropping scrapes and copying the swerve examples, and hide the cameras some of the time.                                    | Hidden crashes 40% vs 30% (cameras vs cameras+skin, p = 0.40); pick success 42% vs 24%; clean picks 28% vs 14%; skin did not clearly help, and picks got worse.                                  |
| Is the doorway pole in the way?      | Watch a short pole in a doorway and see if a straight reach would hit it.                                                                     | Sideslip 1.6 cm vs 7.2 cm and often misses the gripper path; we did not collect the big set.                                                                                                     |
| How often does corridor skin fire?   | On a hallway pick-and-place set, count how often a sensor sees a surface inside 20 cm and inside 50 cm.                                       | Hits 11% vs 40% of sensor tiles (20 cm vs 50 cm); one upper-arm sensor is on 100% of the time because it sees the robot itself.                                                                  |
| Compress the skin readings           | Train a small network to turn each sensor patch into a short code and a nearby-point guess.                                                   | Valid-tile score 100%; point error 20.6 mm vs a 20 mm target; picture match 87% vs 95%; this grades the compressor, not the robot.                                                               |
| Repeat on a hallway pick-and-place   | Train cameras-only and cameras+skin robots on 152 hallway examples from a coauthor and test them.                                             | Local **n=50** (not a paper number): place success **28% vs 42%** (ACT vs PACT), bar hits **34% vs 36%**, no-crash 66% vs 64%; Fisher p = 0.21 and 1.0. No safety win; success gap is noise. n=20 smoke (15% vs 35%, bar 30% vs 20%) was luck. |
| Collect a taller doorway pole        | Put a tall pole on the path of the hand and collect new examples so cameras cannot explain the dodge.                                         | No result (0 examples collected).                                                                                                                                                                |
| Blur cameras only at test time       | Take a finished robot, blur only the camera pictures during the test, and leave the skin unchanged.                                           | No result (0 of these tests run).                                                                                                                                                                |
